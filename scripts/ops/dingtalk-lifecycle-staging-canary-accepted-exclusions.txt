# the owner exclusion list of scripts/ops/attendance-window-runner-pipeline.lib.sh

# reviewed migration source content; scripts/ops/dingtalk-lifecycle-canary-exclusion-consistency.test.mjs

# no longer in the lib list, or a lib name is not listed here: the lib list and this table name
# the same set and change together in one reviewed change. Before a non-off dispatch the canary
# workflow also checks every digest against the migration source at the deployed commit
# (scripts/ops/dingtalk-lifecycle-canary-accept-digests-at-deploy-sha.sh). On the host the
# canary reads names only; action=off never reads this table.
