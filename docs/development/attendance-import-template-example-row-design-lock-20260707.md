## 1. 现状与修法

- 后端「下载 CSV 模板」(template.csv) 已产出 `表头 + 一行示例`（`profile.templateSampleRow`）。
- 前端「下载模板（所选列）」当前产出 `表头 + 一行空值` —— **无示例**。本刀改为 `表头 + 示例行`:
  每勾选列填入 #3791 的 per-column 示例（日期→2026-06-01 / 工号→EMP001 / 姓名→张三 /
  上班1打卡时间→2026-06-01 09:00 / 加班小时→8.5 / 考勤结果→正常…），未知列留空（占位 `—` 不入）。
- 与后端固定档"表头+一行示例"一致 → 导入行为无新风险模式（用户以真实数据替换示例行,标准 CSV 模板 UX）。
- 状态文案更新为「含示例行 / with an example row」。

- 显式格式**文字**（YYYY-MM-DD 等）留在页面「列格式说明」表格（#3791）——CSV 内塞纯格式文字行会被
  当数据误导入,文件内用**示例行**演示格式最稳。
- 后端/接口零改动;`buildTemplateExampleRow` 纯函数复用 #3791 的 format rows。
