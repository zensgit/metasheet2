## 代码变更

未填写企业名称的旧集成，保存其他配置时不应凭空提交 `corpName: ""`。企业名称未改动时，现在省略该字段，由后端保留现值；只有实际改名或明确清空已保存名称才提交它。创建集成时的非空企业名称仍可保存。

这样既保持旧调用的请求形状，也避免普通保存携带过期名称。企业名称是管理员维护的展示元数据，不能替代 Corp ID 或证明外部企业身份；未根据登录应用所有者猜填名称。

回归补齐未知／已知名称未改动时省略字段，明确清空从“已有名称”开始验证；既有选项选择器的精确请求契约不放宽。连通性测试中未改动的企业名称同样不再额外发送。
