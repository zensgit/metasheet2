## 2. 过程中的教训（已写入各片验证文档）

- UI 样式守卫（UF-6）禁止编辑器样式里出现颜色字面量，连 `var()` 的回退值也不行；1b 首跑因此红过一次。之后各片本地都跑 `ui-foundation-style-guard`。
- 后端 `unit (20.x)` 偶发 vitest 进程间通信超时（测试全过、只报 3 个未处理错误），1a 遇到一次，重跑失败作业即绿。
- 执行日志的步骤结果不带步骤键，日志接口也不回规则快照，所以历史只能按位置 + 类型对应；规则改过就明说对不上。
