## 1. 本轮收敛目标

本轮不再扩展线下培训、直播、混培、问卷、证书或复杂反作弊，产品目标收敛为一条可验证的线上培训闭环：

1. 员工在可见课程中在线报名；
2. 进入视频课程并由服务端累计有效观看；
3. 观看过程中按服务端挑战完成一次简短验证；
4. 视频达到完成策略后才允许开始客观题考试；
5. 服务端自动判分；
6. 员工能在课程列表与考试复盘中看到成绩和通过状态。

## 2. 稍强但简单的观看验证

采用 2×3 随机验证格：服务端下发两个有顺序的符号与数字目标，前端在挑战出现时随机排列六个候选，用户依次点击两个目标。

- 候选位置在每次挑战中随机，但显示后保持稳定，避免可用性问题；
- 错选、逆序或超时均不增加观看进度；
- 正确确认后才恢复视频和 heartbeat；
- 服务端保存挑战状态并判定结果，客户端不能自行声明通过；
- 不请求摄像头、麦克风、人脸或生物特征。

该机制能提高固定坐标脚本和简单挂机工具的绕过成本，但不宣称可以阻止具备视觉或 DOM 理解能力的高级自动化。

## 3. 在线报名语义

报名是当前用户对可见自学课程的不可变审计记录，不等同于指派：

- 不产生必修义务、截止时间、催学、学分或容量占用；
- 不创建 assignment member；
- 课程可见范围收缩后，报名审计仍保留，但不会越权恢复学习访问；
- 相同 requestId 与相同载荷重放原结果，异载荷返回 values-free 冲突；
- org、user 与时间均由服务端权威上下文产生。

## 4. 新增闭环证明

新增真实 PostgreSQL 集成测试 `elearning-online-training-loop.db.test.ts`，在同一数据库上串联：

`报名 → 无指派确认 → 开始观看 → 服务端累计并固化完成证据 → 开考 → 提交客观题 → 自动判分 → 复盘与课程成绩回显`

另有负控证明：缺少服务端视频完成证据时，考试以 `prerequisite_incomplete` 拒绝，且不会创建考试 attempt。
