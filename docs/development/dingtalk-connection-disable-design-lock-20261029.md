# 钉钉企业／集成停用设计锁

停用仅改变目录中登记的钉钉企业应用连接的操作状态。保留本地组织标识、账号、业务数据、目录镜像、成员关系、权限和登录授权；企业更名只改变展示名，切换企业微信不在本切片内。

- 管理员选择单个集成，或同一本地组织＋Corp ID 下全部钉钉集成。目标组织从已有记录解析，不接受客户端指定 orgId。
- 独立 `config.connectionDisabled` 标记，默认缺失即未停用，不复用组织 `status`。普通配置保存必须保留该标记。无删除和自动恢复接口。企业级停用还阻止新建同组织同企业连接绕过停用；普通保存不能更换停用连接的应用标识。
- 预览为只读；停用为幂等事务。共享应用凭据跨越选定范围时拒绝，不扩张停用范围。
- 同步入口在解密和取租约前拒绝停用连接；同步落库在现有 source-freeze 锁下再次检查，阻止已经取完通讯录的旧任务落库。
- 注册集成的通知、动作卡片、交互卡片及待办写入在 HTTP 出站前检查连接状态，持有同一连接锁至调用结束。停用等待此前已开始的请求结束；锁超时则返回冲突，不能报告成功。已发出的消息不能撤回。新到达的历史交互卡片回调将拒绝，已经进入审批处理的入站请求不取消；本地审批入口和权限不变。
- OAuth 登录及容器登录令牌流程不纳入停用；未关联目录集成的应用不凭猜测归入某企业。已有停用连接时，未登记应用或缺少发送上下文的旧发送请求均拒绝，需先登记其归属；其他已登记且正常的组织不受影响。
- 有来源的发送同时验证任务／账本的 integrationId 和实际 AppKey；全局凭据不能替换来源。审批卡片更新缺少权威来源时不发送。HTTP 成功后守卫事务提交失败，按 outcomeUnknown 处理，禁止自动重发；出站前拒绝与真实传输错误保留原分类。普通保存按已读 AppKey 做 CAS，拒绝旧表单重新挂回停用应用。
- 不改任何外部写开关，不调用真实钉钉 API验证；仅 Mac mini 合成数据与假发送器验证。

## 验收门槛

| 门槛 | 证据 |
| --- | --- |
| 单集成／企业范围及跨组织隔离 | 单元和真实 PG 合成测试 |
| 不触碰账号、成员、业务表和登录授权 | 数据指纹；停用写 SQL 白名单 |
| 同步入口和落库复检 | 定向回归和守卫变异负例 |
| 发送停用与正在发送的竞态 | 假 HTTP＋真实 PG 锁并发测试 |
| UI 预览、确认与失败态 | Vue 回归及合成截图 |
| 默认行为与登录授权不变 | 邻接回归、类型检查、validate:all |

独立群机器人 Webhook 没有目录集成／企业归属，不能由应用凭据安全推断，本切片不自动关闭它们；迁移离开钉钉前须另行盘点和处理，不可把本功能当作所有钉钉出口的总开关。

合并、真实解绑、在线配置、部署和启用另批。本分支已普通合入 #6640 的展示代码并执行组合验证；staging 在线状态仍须单独验收，不据此宣称线上可用。
