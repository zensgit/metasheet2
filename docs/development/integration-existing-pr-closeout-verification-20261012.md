## 原因与最小设计

生产读取守卫只允许 `metadata.filtersApplied === false` 的未过滤结果在本地过滤。声明已过滤或缺失声明却返回越界行时，应以 `read_row_mismatch` 拒绝。旧测试对 false/true/absent 均期待过滤成功，原整文件59条中36条失败；#6324/#6337 正式 Guard 及本地原文件复现一致。

修复明确区分合法未过滤源和越界响应：

- false 保留成功结果、数量、父子关系；true/absent 精确断言错误类型、对象、字段及页码，不接受任意失败。
- 递归和子树负例先证明进入对应真实读取；改名字段覆盖三种过滤声明。
- 版本类型严格相等、循环、深度和缺失子 BOM 继续进入其原验证路径。
- 分页 false 继续两页并计原始行数；true/absent 首页拒绝且不读取第二页。
