## 1. 已复现问题

1. `stock-preparation-bom-expansion.cjs` 的 `readAll` 仅在 `requireCompleteBatch` 为 true 时拒绝 `done:false` 且没有下一游标。普通 dry-run 未启用该选项，把只返回 A 的订单当作完整 A/B：真实 dry-run 可应用，真实内存 apply 新增 A，并可把已有 B 标记失活。该复现使用实际 expander / table-actions / planner / writer，只有源与目标存储为合成边界。
2. `StockPreparationSourceBindingPanel.vue` 不订阅认证事件或作用域变化；同挂载切换后旧 schema 草稿、JSON 预览仍在，旧 FileReader 还能覆盖新会话。真实 Vue 内存挂载已复现；不涉及客户读取。
