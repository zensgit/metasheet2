## 5. 两条路径:最小可信 vs 完整对标

**最小可信完整客户**(能拉 BOM→备料网格→部门协作→物料匹配→异常→日期级联→跨批继承→生成备料行,**内部闭环、不写回 K3**):
`G0 → W1 → W2 → W3 → W4 → C1 → G1 → (G3a+G3b 生产激活)` ≈ **累计 M-L 级,数周**。

**完整参考系统对标**(再加图号识别 + 工艺建模 + **真写回 K3**):
`+ G2(需 D2 先落) + C2 + G4(K3 写回,L)` ≈ **再加数周,且 G4 过需求门**。

## 6. 一句话

**已完成 ≈ 地基砸实(可行性实证)+ 核心零件备齐(4 模块已建已审)。** 距离一个完整客户上线:
最小闭环还差 **W1-W4 接线 + G1 通知 seam + G3 激活**(数周,全在 G0 ratify 后);完整对标再加
**G2 图号(等 D2)+ C2 工艺 + G4 K3 写回(大,需求门)**。**没有任何一刀是「按一下就有」——每刀过对应门。**
