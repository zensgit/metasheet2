## 两项最小修改

1. 临时合成试用使用简短固定登录名；该名称不是秘密。每次仍创建独立临时数据库，owner/tenant 仍分别生成 UUID，密码仍来自 24 个加密随机字节，仅写私有交接文件。正式认证、权限、TTL 60–900 秒、所有权清理及发送默认 OFF 不变。
