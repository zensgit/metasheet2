# SA-04B：多项目物料的可配置静态展开

2026-09-30。本地实施合同，承接 `yida-static-preview-design-20260930.md`；只增加已有面板的本地数据准备，不新增 endpoint、认证、权限、远端查询或发送。不是 SA-05 授权，不更改生产数量或查重口径。

## 1. 源码依据与不照搬的行为

用户提供的非 Git 旧源码快照中，`controller/StockInfoController.java:1757–1769` 按项目循环创建物料表单；`:1812–1833` 小数 HALF_UP 到一位，整数分不尽却继续发送空数量。它不能作为安全的新数量 oracle。`:1869–1886` 的旧查重是项目/图号/名称/规格/材质/版本加父图号，不等同于当前静态示例的项目+明细键，也不保证远端并发幂等。项目目录、发料确认及工艺更新分别是其他业务动作，不在本片偷偷执行。

代码候选 HEAD 为 b35d4cd1fbaa50d0cf15e1a75745f77624a9468a，叠前序本地切片。当前 `yida-static-plan.mjs` 是一行映射一表单，Panel 要求用户预先整理；本片直接接该真实 Panel，把明确的项目展开工作交给配置，不新增无消费者 helper。

## 2. 用户明确选择，不默认决定舍入

默认保持“每表单一行”的原模式。用户可以显式选择两种候选分配规则：

- `equal_integer`：非负安全整数件数，只允许项目数整除。
- `equal_decimal_exact`：允许至多六位小数的非负数量，只接受不舍入且可在六位内精确表示的均分。六位是本地实现精度上限，不是厂商约定；超限拒绝而非截断。

必须填写明确的项目列表（一行一个完整项目号）、源项目字段及源数量字段。项目列表1–20项，非空、每项有界、去首尾空白后重复则拒绝，不自动去重或解析旧范围/斜杠语法。项目字段与数量字段不同，均须在已有 fieldMap 中，分别为 string/number；业务键必须包含项目字段及至少一个用户选择的其它源字段。只允许 create 意图，禁止把同一个 update instanceId 扇出到多个项目。

这两个模式只是本地候选，不能被标成业务 owner 已批准的生产政策。需要余数归属、舍入、中文单位文本解析、真实旧复合键、版本变更重建、工艺或发料策略时仍需明确合同；不自动套入其他模式。用户也可继续使用原模式，显式提供已分配的每项目行。

## 3. 单一生产链与数据边界

新增无 I/O 纯 ESM `stock-preparation-yida-allocation.mjs` 及类型；只接本地 rows JSON 文本、现有静态 config 和闭集 allocation 设置。输入行复用现有 `parseYidaStaticRows`，不再发明第二份行解析规则；结果候选交给同一个 `buildYidaStaticPlan`。没有导入网络/时钟/存储/凭据模块。

数量用有界十进制整数缩放运算，不用浮点近似判“守恒”。输入必须是 number，文本单位仍是独立普通映射字段，不从混合数量字符串猜取。禁止负值、非有限值、超精度或超安全范围。同时核验原始 JSON 数量 token，不能让 JSON.parse 的舍入或下溢将非法数量修成合法；重复数量键拒绝。源数量与分配结果的可表达性都检查，无法无损转回现有 number 目标就拒绝。0 保留。整数模式 `6/3→2`；小数模式 `1.5/3→0.5`；`1/3` 不近似为0.333333。

复用原128 KiB/100源行限制，展开后也不得超过100行；超限不截断。任一行分配失败则整批不产生下游计划，只返回固定粗码/源行索引及本地分析，不静默跳过坏行。全部分配通过后，逐源行×项目复制既有平面数据，仅替换配置指定的项目和数量字段；不改原输入，不覆盖其它业务字段。项目字段是显式项目清单的覆盖槽，来源值可缺省或被覆盖，不用它认证项目身份。除此槽外，重复业务键、缺字段和映射类型错误仍由现有 planner 逐行拒绝，不在准备层“修成合法”。

固定 `canApply:false`、`tokenIssued:false`、`lookupExecuted:false`、`externalWriteAttempted:false`；远端始终未核验。本地展示可包含用户的项目和数量，但公共 evidence/错误只有计数和粗码；不上传、打印或持久化输入。

## 4. 可见结果与验收

在现有静态 Panel 内显示来源行、原总量、项目数、每项目分配量、分配合计和差额。项目清单及数量字段可以随第二套全改名布局配置；正常相同业务输入应产生相同目标候选内容，不声称不同源字段名生成相同本地身份。切换模式、角色、项目、映射、输入或意图都清旧结果；原退出/切项目卸载机制继续有效。

验收：真实模块→真实既有 planner、真实 Vue 点击；整数/小数两种显式模式、0、不可整除/需要舍入、重复项目、输出超限、缺字段、update拒绝、第二布局、输入不变、重复键继承、任何编辑清结果、零新增网络。预演结果必须实际出现后才能断言零发送。数量守卫/项目键/输出预算/实际 planner 接线各有定向变异；主审与独立审查负责证据，不靠作者自证。

本片无迁移、没有外部状态；回滚仅移除新增本地模式，不改变现有配置/连接/远端表单。未来发布遵循既有授权，当前只做本地合成开发。
