# 目录集成错误态与企业名称展示

## 范围

列表请求失败不等于没有集成。加载中、成功为空、成功有数据、失败四种状态分别显示；失败提供只读重试，响应缺少 items 数组同样视为失败。成功获取列表后的详情错误不改写列表状态。

企业名称使用可选的 `config.corpName`（管理员已确认的展示名称，最多 200 字符）。名称、Corp ID、本地组织分别显示，名称未知明确标注；不根据集成名称、部门名称或登录应用所属组织推断。旧调用省略字段保留原值，空字符串清除，非法类型拒绝。仅增加 JSON 配置字段，无迁移。

## 边界

不绕过生产加密材料检查，不在页面打开时调用钉钉获取名称，不修改账号关联、Corp ID 不可变规则或同步行为。名称是人工维护的展示信息，不是钉钉 API 实时认证结果。

历史加密材料追查仅读取 staging 的既有配置和必要密文，在 Mac mini 私有副本离线验证；证据仅记录计数。线上配置、密文重加密、真实回填、合并、部署、启用另批。

## 验收门槛

| 门槛 | 验证 |
| --- | --- |
| 失败不显示空态，重试可恢复 | Vue 回归：500、网络失败、无效响应、加载态、成功为空 |
| 名称与两种组织标识不混淆 | Vue 已知／未知名称、后端创建／读取／保留／清除／非法输入 |
| 不削弱安全边界 | 生产加密材料拒绝测试、租户不可变邻接测试 |
| 历史材料结论有正反例 | Mac mini 密文副本解密计数、错误材料与损坏密文负例 |
| 前端测试确实进入 CI | 复用现有 directoryManagementView.spec.ts 的两处登记 |
