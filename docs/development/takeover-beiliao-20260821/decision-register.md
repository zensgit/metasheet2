# 备料接管 · 决策登记册

> **用途**:此前决策散在四套并行编号里(状态账本 O-1…O-6 / 首载 ADR O-A…O-F / 竖切 D-1…D-4 / 上线门决策#5),同一件事在不同文档里叫不同名字,没人说得清还欠几条。本册是**唯一的编号真源**。
>
> **纪律**:任何决策的**层级变更**(owner ↔ 技术负责人),必须在同一个 commit 里同步修订原出处的脚注(状态账本 §5、上线门 §1、ADR §5),**不得只在本册改口**。
>
> **层级**(章程):**O** = owner 先批后动(真实客户数据 / 生产写入 / 外部系统写回 / 花钱·对外发布·发送);**T** = 技术负责人默认前进 + 24h 异步否决。
>
> values-free:不含主机 / IP / 口令 / 凭据。
