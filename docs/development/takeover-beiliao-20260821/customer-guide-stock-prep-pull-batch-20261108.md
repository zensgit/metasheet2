# 批次标识使用说明（给客户）

> 读者：备料主管理员、拉取人员和备料人员。
> 本文不含任何项目号、物料号、主机或账号；例子里的物料用 S-01、P-07、X 代替。
> 依据：设计定稿 design-final §5.5、§10，决策登记 R-65。界面文字照系统里实际显示的写（批次标识前端 #6817、设置页 #6815）。

## 1. 表上多了哪两列

装好批次标识以后，每张项目备料表多出两列：

| 列 | 意思（系统里的原话） |
|---|---|
| **首次批次** | 「首次批次：这个物料在本项目第几批拉取时第一次出现；不表示这一行已经备过料。」 |
| **本次拉取** | 「本次拉取：这一行是在第几批拉取时建立的。」 |

几点说明：

- **一次拉取 = 一个批次。** 只有新增了物料的那次拉取才算一个新批次。没有新增物料的拉取（只是更新），同步面板上会显示「本次没有新增物料，不产生新的拉取批次」。
- **本次拉取 = 建立这一行的那次拉取，不是最近一次拉取。** 以后的拉取改了这一行，或者把它标成失效，这一格都不变。
- **首次批次按物料判断**（本客户采用的规则）。同一个物料在第 1 批出现过，第 2 批又在别的位置出现时，那一行显示首次=第1批、本次=第2批。
- 两列由系统自动写，人工改不了。

### 例子（owner 认可过的样例）

第 1 批拉了 S-01；第 2 批来了 P-07，P-07 下面也有 S-01：

| 物料 | 有效 | 首次批次 | 本次拉取 |
|---|---|---|---|
| S-01（第 1 批建的那一行） | 否 | 第1批 | 第1批 |
| S-01（第 2 批建的那一行） | 是 | 第1批 | 第2批 |
| P-07 | 是 | 第2批 | 第2批 |

## 2. 格子里可能看到的字

| 显示 | 意思 |
|---|---|
| `第2批（2026-11-07）` | 第 2 批，日期是那次拉取的服务器日期（批次格式选「第N批」时只显示 `第2批`） |
| `第1批（推定，2026-10-20）` | **推定**：这批是装批次标识**以前**的历史拉取，系统根据行的建立时间和拉取痕迹推算出来，拉取次数由贵方确认过。推定的序号是可信的，但不是当时实时记下的 |
| `历史批次未知` | 历史上是第几批无法确定（比如历史次数对不上，或者有更早的行看不出来历），系统宁可写「未知」，也不猜 |
| `人工补充` | 这一行是人工补充的，不是拉取建立的，两格都显示「人工补充」 |
| 两格都空 | 右击复制的行、导入的行、自动化或表单建的行，以及没有走「人工补充」的手工新建行：这些都不打批次 |

## 3. 打开表时看到什么

- 装好以后，从多维表左栏点开项目表，默认进入**「备料填写视图」**，只显示**有效 = 是**的行，两列都能看到。工作台、项目备料页的链接也是一样。
- **要看全部行**（包括已经失效的老行），切到「**全部记录**」页签就行，一点就到。
- 如果贵方在设置里选了「保持现场现在的默认视图」，打开表时还是今天的视图，不会变。
- 有人用过个人列顺序的，会在自己列序的最后看到这两列；可以自己拖到想要的位置。

**请特别留意（重复建的表）：** 如果某张表以前第 2 批把第 1 批的物料又建了一遍，装好以后默认视图换成备料填写视图，第 1 批那些已经失效的行里填过的内容，在默认视图里就看不到了；对应的有效行显示首次批次「第1批（推定…）」，填写列是空的。两份都还在「全部记录」里。批次标识只是让这种重复**看得出来**；要把填过的内容挪过去还是保留，是另外一次需要批准的修复，不在这次范围内。

## 4. 项目备料页和同步面板上的提示

| 提示 | 意思 |
|---|---|
| 最近拉取批次：第N批（日期） · 共 K 批 | 正常 |
| 批次标识已启用，还没有拉取批次；下一次有新增物料的拉取会记为一个新批次。 | 新表，正常 |
| 批次标识：未启用 | 这张表还没装批次列 |
| 批次标识安装中，暂停拉取 | 管理员正在装，装完就能拉 |
| 批次标识暂停：有 n 行未登记批次，请联系管理员补登记 | 有行没记上批次；拉取照常，只是新增的行暂时不记批次，等管理员补登记 |
| 本次新增 n 行，记为 第N批（日期） | 刚拉完，记了一个新批次 |
| 本次新增 n 行，并入 第N批（同一次拉取的重试） | 同一次拉取重试，没有开新批次 |

## 5. 设置页（「数据来源与体检」→「批次标识设置」）

只有备料主管理员能看到、能改，每次修改都记审计。默认值就是 10-27 方案。

| 设置 | 可选值（默认值在前） | 什么时候锁定 |
|---|---|---|
| 首次批次判定 | 按物料 / 按位置 | 这张表一有批次标签就锁定 |
| 批次格式 | 第N批（日期），例如「第2批（2026-11-07）」 / 第N批，例如「第2批」 | 这张表一有批次标签就锁定；已写的标签不会改写 |
| 打开表时的默认视图 | 改成备料填写视图 / 保持现场现在的默认视图 | 装批次列时执行一次，之后锁定 |
| 两列位置 | 最左 / 最右 | 两列建好后锁定；放最左会让某些视图失去冻结列时，装机时要逐表明确选择 |

- 改默认值只影响**之后**新建或装批次列的项目表；已经记下设置的表不变。
- 选「按位置」时，带「推定」的首次批次是按今天的「有效」状态推算的，可能和当时实时拉取会写的不一样。
- **不可配置**（页面上明确写出来，省得去找开关）：
  - 本次拉取 = 建立这一行的那次拉取（不是最近一次拉取）
  - 正式导出不含这两列
  - 回收站里的行不算「出现过」
  - 首次批次列总是显示

## 6. 这次不包括

- **正式导出不含这两列。** 要不要放进正式导出，需要双方另外约定（O-BI-6）。
- **没有「最近一次拉取」的含义。** 本次拉取只表示建立这一行的那次。如果确实需要「最近一次被拉取更新」，以后另加一列，不改这一列的含义。
- 复制出来的表不受批次标识管理，以项目表为准。
- 网页上没有「安装批次列」的按钮，装机由我方管理员在批准的窗口里做。
