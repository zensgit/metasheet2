## 二、升级步骤(与 r7 的差别:用脚本,不再手打)

1. 打包:`bash scripts/ops/multitable-onprem-package-build.sh`(Windows 打包机需 zip 或 7z 垫片);
2. **升级即一条命令**:`scripts/ops/multitable-onprem-package-upgrade-inplace.ps1 -PackageZip <zip>`——
   校验和验证 → 停服 → 备份 → 换包(逐文件遍历)→ **逐文件哈希门** → 迁移(env 载入进程)→ 起服 → 健康轮询;
   任一断言失败:**停服 + 打印恢复指引**,绝不带伤重启;
3. 升级后:跑预检(应 `ready: true`)→ 跑自举脚本(判据自动断言)→ 推 tag `deploy-r8-YYYYMMDD`;
4. **新验收项**:打开安装页(工作台内),确认默认配置面板渲染、预检面板绿、九步安装全 OK/SKIP 无 FAIL。
